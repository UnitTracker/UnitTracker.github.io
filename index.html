What this is

A loaner-unit tracker that runs entirely on this computer — no internet, no accounts, nothing in the cloud. Your information is saved automatically on this laptop and never leaves it. Version 3.1

The tabs

All Units

The complete master list of every device. Nothing ever leaves it — the other tabs are just filtered views. Add units, tag them, set where each one is, and reserve future loans.

Out on Loan

Short-term loans only, kept lean. Watch Days Left for what’s due soon or overdue.

Long-Term

Permanent / long-term loans, with the holder, the responsible account manager, and a since-date.

TFS Support

A tag, like “On account.” Any unit can be marked TFS and still be in-house, out, or long-term.

Returned

A history log of completed short-term loans, plus units removed from the master list (with the reason).

Placement vs. tags

Every unit has one placement — where it physically is right now — plus three independent tags:

  • Placement (one at a time): In-house · Out (short-term) · Long-term
  • On account — the unit is owned / registered to us.
  • TFS — flag it for the TFS Support view; works alongside any placement.
  • US→CA — the unit is on loan from the US into our (Canada) department.

All three tags are set with the checkboxes in a unit’s Add / Edit screen.

Everyday tasks

➕ Add a unit

On All Units, click ＋ Add Unit → enter Model and Serial Number → tick any of On account, TFS Support, From US → Canada → Save. If a unit with the same model + serial already exists, you’ll get a warning first.

📤 Short-term loan

On All Units, click Loan Out. Fill in the customer, the Account Manager, dates, courier and waybill → Loan Out. It appears on the Out on Loan tab.

📎 Long-term / permanent loan

On All Units, click Long-Term. Set who has it, the type, the Account Manager, a since-date and notes. It appears on the Long-Term tab — not in Out on Loan.

📅 Reserve / request a loan

In the Requests column on All Units (or Out on Loan), click ＋ Reserve. Enter the requested start date and days on loan, plus customer / account manager / notes. You can reserve a unit even while it’s out on loan — as long as the dates don’t overlap. If they do, a warning pops up naming the conflict and lets you save anyway or change the dates. The button then shows how many requests a unit has and the next date.

📥 Return a short-term loan

Click Return (on All Units or Out on Loan). Enter the incoming waybill, date of return, and service order # → Confirm Return. It moves to Returned. (For long-term, use End to send it back to in-house.)

🗑 Delete a unit — two ways

Click ✕ on a unit and choose: Delete everything (unit + all history, permanent), or Remove from master list but keep its history in Returned — with a reason box (e.g. “sold”, “customer keeping unit”). The reason shows on the kept records in the Returned tab.

Days Left colours: green = plenty of time · amber = due within 3 days · red = overdue. Most overdue at the top. All dates read like Aug 18, 2026.

Where your data lives

Two things are kept separate:

  • The app — the index.html file (the buttons and layout). This is the only thing that changes when you get an update.
  • Your data — the units, loans, requests and account-manager list. Saved automatically on this laptop, and (if you set it up) in a backup file you control.

Because they’re separate, replacing the app file does not erase your data.

📂 Back up your data

Click the 📂 button at the top-right. Two options:

  • 🔗 Link a backup file — pick or create a file called loaner-data.json once; after that, every change is written into it automatically for the session. Recommended.
  • 💾 Save a backup copy — save a one-time snapshot anytime.

Keep that loaner-data.json somewhere safe — a USB drive or a synced folder. It protects you if the laptop ever fails, and it’s exactly what you’d hand to a colleague.

⬆️ Apply an update (new version)

  1. Open the app and save a backup copy first (📂 → Save a backup copy). Quick insurance.
  2. Overwrite your old index.html with the new one — same folder, same filename.
  3. Reopen the file. Your data should still be there.
  4. If it looks empty, click 📂 → Restore / import → choose your loaner-data.json. Everything comes back.
The golden rule: keep the app in the same folder with the same name, and always keep a recent backup file. Do that and you’ll never lose anything on an update.

📥 Restore or move to another computer (upload)

  1. Open index.html on that computer (Chrome or Edge).
  2. Click 📂 → Restore / import from a backup file.
  3. Choose your loaner-data.json file → confirm. All units and history appear.
Importing replaces whatever is currently on screen with the file’s contents — so only do it when you want the file’s data to take over.

🔒 Security & good habits

  • Your real protection is your Windows login and BitLocker drive encryption — keep both on.
  • The backup loaner-data.json is plain readable text, so treat that file and any USB like a confidential document.
  • Keep the app in one place, and save a backup regularly (e.g. weekly, or after a busy day).
